# NumPy 20 Programs

This repository contains **20 NumPy programs** covering important NumPy concepts and basic applications.

## Topics Covered

1. Creating NumPy arrays using `arange()`
2. Creating arrays of zeros using `zeros()`
3. Finding `ndim`, `shape`, `size`, and `dtype`
4. Accessing elements from a 1D array
5. Selecting columns from a 2D array
6. Reshaping arrays
7. Transposing matrices
8. Performing arithmetic operations on arrays
9. Creating feature matrices
10. Calculating feature-wise mean using `axis=0`
11. Filtering rows using conditions
12. Standardizing feature columns
13. Creating random matrices using a fixed seed
14. Matrix multiplication using `@`
15. Broadcasting and adding bias
16. Calculating Mean Squared Error (MSE)
17. Creating grayscale image arrays
18. Creating batches of RGB images
19. Handling `NaN` values using `nanmean()`
20. Understanding the difference between `*` and `@`

## Requirements

* Python 3
* NumPy
* Jupyter Notebook / VS Code

## Installation

Install NumPy using:

```bash
pip install numpy
```

## How to Run

The programs are written using Python and Jupyter Notebook (`.ipynb`).

1. Open the notebook in VS Code or Jupyter Notebook.
2. Select a Python kernel.
3. Run each cell to view the output.

## Purpose

The purpose of this repository is to practice NumPy concepts and develop a basic understanding of numerical computing and array operations in Python.
